# 📊 Social Media Analytics Dashboard (Power BI)

## Project Overview
This project is an interactive Power BI dashboard designed to analyze social media performance using key engagement metrics.

## Features

- Total Reach
- Total Likes
- Total Comments
- Total Shares
- Engagement Rate
- Platform-wise Analysis
- Region-wise Reach
- Content Type Performance
- Interactive Filters

## Tools Used

- Power BI Desktop
- Power Query
- DAX
- Microsoft Excel

## Dashboard Preview

![Dashboard](images/dashboard.png)

## Key Insights

- Identifies top-performing platforms.
- Compares engagement across content types.
- Analyzes regional audience reach.
- Tracks overall engagement trends.
